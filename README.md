# たてによむ

SSを小説のように読む、ブラウザ完結の縦書きリーダーです。

## 使い方

`dist/index.html` をブラウザで開くだけで動きます。ビルド・サーバー・外部APIは不要です。Webに置く場合は `dist/` を静的ホスティングの公開ディレクトリにしてください。

- テキスト貼り付け／TXT読み込み（UTF-8・Shift_JIS）
- 明朝体／ゴシック体、文字サイズ14〜28px
- 文庫・ラノベ（105×148mm）、新書（103×182mm）、単行本・四六判（127×188mm）
- 1行は約28〜32文字以内。画面が小さい場合はさらに短くなります
- 縦書き用の字形、厳格な禁則処理、ページ境界での約物調整
- 右へのスワイプ／左矢印キーで次ページ、左へのスワイプ／右矢印キーで前ページ
- ページスライダー・ページ番号による移動
- ページしおり・選択文ハイライト・保存箇所一覧・削除
- 文章中の位置を記録するため、再組版しても保存箇所に移動可能
- 初期画面は本棚。本ごとに「読む／続きから読む」「エクスポート」、本棚上部に「インポート」「本をつくる」
- 読書位置の自動保存と没入型リードモード。没入中は本文だけを表示し、スライダー・矢印・ボタン・ページ番号を非表示
- ワンタップで操作ボタンを表示・非表示。本文の組版は切り替え時も維持
- ページ右上にしおりボタン、上部にテーマ・書体の直接切り替え
- テキスト長押しで範囲を選択するとハイライトボタンが表示。長押しによる一般メニュー表示は廃止
- 原文編集モードと読書モードを切り替え、下書き自動保存
- ライト／ダークモード切り替え
- ブラウザへの明示保存と「保存した本」の一覧
- 編集範囲外の保存位置は追従。編集範囲内のしおり・ハイライトは解除。変更前の本も保存
- 読書データ（`.tatebook` / JSON）のエクスポート・インポート。本文・タイトル・しおり・ハイライト・読書位置・書体・文字サイズ・判型・テーマを引き継ぎ
- オフラインで読める単一HTMLのダウンロード（本文・設定・しおり・ハイライトを同梱）
- 選んだ判型でPDF保存（ブラウザ印刷画面から「PDFに保存」、10.5pt）

## 保存とプライバシー

本文は外部送信せず、localStorageに保存します。別の本を開いたあとでも、同一本文を再入力すると保存位置・しおり・ハイライトが復元されます。ブラウザの保存データを消すと失われるので、必要ならHTMLを書き出してください。HTMLを他人に渡す場合はしおり・ハイライトも含まれます。保存領域が利用できない場合は警告を表示し、そのセッション内で動作します。

添付されたユーザーのSSはリポジトリにもサイトにも同梱していません。初期表示はオリジナルの短いサンプルです。

## 組版と対応環境

`writing-mode: vertical-rl`、`text-orientation: mixed`、OpenType `vert` / `vrt2` を使用。フォントは端末にある游明朝・ヒラギノ明朝・Noto Serif CJK JP等、および対応するゴシックを優先します。フォントは埋め込んでいないため、端末の日本語フォントによって字形・ページ数が変わります。欧文は横倒しで組みます。

画面上で実測して改ページし、Unicode書記素を途中分割しません。PDFは別途判型に合わせて再組版するため、画面とページ番号が一致しない場合があります。PDFにハイライトを残すには印刷設定の「背景のグラフィック」を有効にしてください。印刷ヘッダー・フッターは無効にし、倍率100%を推奨します。保存ダイアログや用紙サイズの扱いはブラウザ・OSによって異なります。

## 検証

`node tests/pagination.cjs /path/to/syousetsu.txt` で、実装の分割関数を使った欠落・重複・Unicode境界・位置検索の回帰チェックを実行できます。テストではレイアウト計測を模擬します。実際の字形・印刷結果・タッチ操作は実ブラウザで確認してください。

## 読書データの移行

本棚 → 本ごとの「エクスポート」→「読書データ」で `.tatebook` ファイルを保存します。別のブラウザで本棚 →「インポート」から同じファイルを選ぶと復元されます。同じ本文の本が既に保存されている場合、その読書状態はインポートした内容で置き換わります。ファイルには本文と注釈が含まれます。PDFは読み取り用の出力で、インポートには対応していません。


## 読書画面・PWA（更新）

本棚の上部は「本をつくる」「インポート」の順です。テーマ切り替えは読書画面のフッターにあります。フッターは明／ゴの書体トグル、太陽／月のテーマトグル、レイアウトボタンのみ。レイアウトモーダルで判型と文字サイズを調整します。上部のメモ一覧は独立した画面で、項目を押すと読書画面の該当位置へ移動します。

没入モードは画面の余白とページ番号部分を除いた領域に再組版します。モード切り替えでページ数が変わりますが、本文中の位置を保持します。没入中も現在ページ／総ページを表示します。操作表示時はページ・ページバー・フッターを上下に配置し、本文にメニューを重ねません。

HTTPSで公開するとPWAとして利用できます。対応ブラウザのインストール機能、または表示される「アプリを追加」から追加してください。iPhone/iPadではSafariの共有メニューから「ホーム画面に追加」を選択します。初回オンラインアクセスでService Workerの準備が終わった後、オフラインで起動し保存済みの本を読めます。本文は端末のlocalStorageに保存されます。ブラウザとホーム画面アプリで保存領域が分かれる環境では、読書データのエクスポート／インポートで移行してください。HTML書き出し版は単独で動作し、Service Workerを登録しません。
