# たてによむ

SSを小説のように読む、ブラウザ完結の縦書きリーダーです。

## 使い方

`dist/index.html` をブラウザで開くだけで動きます。ビルド・サーバー・外部APIは不要です。Webに置く場合は `dist/` を静的ホスティングの公開ディレクトリにしてください。

- テキスト貼り付け／TXT読み込み（UTF-8・Shift_JIS）
- 明朝体／ゴシック体、文字サイズ14〜28px
- 文庫・ラノベ（105×148mm）、新書（103×182mm）、単行本・四六判（127×188mm）
- 1行は約28〜32文字以内。画面が小さい場合はさらに短くなります
- 画面幅900px以上（デスクトップ）では、紙の大きさを選んだ判型の比率・幅に固定。レイアウト設定の「ページ表示」で1ページ／2ページ（見開き）を選べます。2ページ時は右ページが前、左ページが後で、ページめくりは2ページ単位です
- 縦書き用の字形、厳格な禁則処理、ページ境界での約物調整
- `￢⊥安倍晋三￢⊥` のように囲むと、囲まれた文字を横倒しに表示（区切り記号は非表示）
- `⊥⊥WHO⊥⊥` のように囲むと、囲まれた文字を回転させず正立で縦に並べて表示（略語向け。区切り記号は非表示、行・ページの途中で分割しません）
- `**太字**` で太字、`~~取り消し~~` で取り消し線（Markdownと同じ半角記号。区切り記号は非表示。中にルビ・横倒し・正立を含められます）
- `[[漢字]]<<かんじ>>` のように書くと、`漢字` に `かんじ` のルビを振って表示（区切り記号は非表示。親文字・ルビとも改行を含まない1文字以上。ルビ付きの語はページをまたいで分割しません）。ルビが親文字より短いときは親文字の幅に均等に配置し、長いときは前後の仮名にルビ1字分まで掛けて親文字の間延びを抑えます
- 禁則処理はJIS X 4051の行頭禁則（終わり括弧・句読点・中点・疑問符/感嘆符・長音記号・繰返し記号・小書きの仮名など）と行末禁則（始め括弧）に対応。「……」「――」・縦中横・ルビの前後でも、閉じ括弧や句読点が行頭に、始め括弧が行末に来ないようにしています
- 右へのスワイプ／左矢印キーで次ページ、左へのスワイプ／右矢印キーで前ページ
- ブラウザでは本文上のマウスホイールでページめくり（下スクロールで次ページ、上スクロールで前ページ）。連続入力は350msごとに1ページまで。本文選択中・設定画面・Ctrl等を押した操作ではページをめくりません
- マウス・タッチ・矢印キーが使えない環境向けに、没入モードでも画面左右の端にページ送りボタンを表示（ホバー可能な環境のみ。太めの矢印を通常時から見える濃さで表示し、ホバー・キーボードフォーカス時にはさらに強調します）
- ページスライダー・ページ番号による移動
- ページしおり・選択文ハイライト・保存箇所一覧・削除
- 文章中の位置を記録するため、再組版しても保存箇所に移動可能
- 初期画面は本棚。表紙を押すと本を開き、続きから読めます。本棚右上のボタンでグリッド表示（スマホでは1行3冊、表紙の「⋯」から編集・エクスポート）とリスト表示（小さな表紙＋詳細。ボタン以外の行のどこを押しても本が開きます）を切り替えられ、選んだ表示は保存されます。本ごとに「編集」「エクスポート」、本棚上部に「インポート」「新規」
- 読書位置の自動保存と没入型リードモード。没入中は本文だけを表示し、スライダー・矢印・ボタン・ページ番号を非表示
- ワンタップで操作ボタンを表示・非表示。本文の組版は切り替え時も維持
- ページ右上にしおりボタン、上部にテーマ・書体の直接切り替え
- テキスト長押しで範囲を選択するとハイライトボタンが表示。長押しによる一般メニュー表示は廃止
- 原文編集モードと読書モードを切り替え、下書き自動保存。原文編集画面の「原文のマークダウン記法」から、ルビ・横倒しの書き方と表示例を確認できます
- ライト／ダークモード切り替え（読書画面用）。本棚などホーム画面のテーマは、本棚上部の歯車ボタン「ホームの設定」で別に選べます（ライト／ダーク／端末と同じ）
- ブラウザへの明示保存と「保存した本」の一覧
- 原文を編集して保存すると同じ本が更新されます（新しい本は増えません）。編集範囲外の保存位置は追従。編集範囲内のしおり・ハイライトは解除
- 読書データ（`.tatebook` / JSON）のエクスポート・インポート。本文・タイトル・しおり・ハイライト・読書位置・書体・文字サイズ・判型・テーマを引き継ぎ
- オフラインで読める単一HTMLのダウンロード（本文・設定・しおり・ハイライトを同梱）

## 保存とプライバシー

本文は外部送信せず、localStorageに保存します。別の本を開いたあとでも、同一本文を再入力すると保存位置・しおり・ハイライトが復元されます。ブラウザの保存データを消すと失われるので、必要ならHTMLを書き出してください。HTMLを他人に渡す場合はしおり・ハイライトも含まれます。保存領域が利用できない場合は警告を表示し、そのセッション内で動作します。

添付されたユーザーのSSはリポジトリにもサイトにも同梱していません。初期表示はオリジナルの短いサンプルです。

## 組版と対応環境

`writing-mode: vertical-rl`、`text-orientation: mixed`、OpenType `vert` / `vrt2` を使用。フォントは端末にある游明朝・ヒラギノ明朝・Noto Serif CJK JP等、および対応するゴシックを優先します。フォントは埋め込んでいないため、端末の日本語フォントによって字形・ページ数が変わります。欧文は横倒しで組みます。半角の「!」「?」は全角相当で正立させ、「!?」「!!」など2文字の組み合わせは縦中横にします。半角の「,」「.」は和文中では縦書き用の全角「，」「．」で表示し、英単語の間（`Hello, world`・`Mr. Smith`）では英文と一緒に横倒しにします。

画面上で実測して改ページし、Unicode書記素を途中分割しません。

## 検証

`node tests/pagination.cjs /path/to/syousetsu.txt` で、実装の分割関数を使った欠落・重複・Unicode境界・位置検索の回帰チェックを実行できます。テストではレイアウト計測を模擬します。実際の字形・印刷結果・タッチ操作は実ブラウザで確認してください。

## 読書データの移行

本棚 → 本ごとの「エクスポート」→「読書データ」で `.tatebook` ファイルを保存します。別のブラウザで本棚 →「インポート」から同じファイルを選ぶと復元されます。同じ本文の本が既に保存されている場合、その読書状態はインポートした内容で置き換わります。ファイルには本文と注釈が含まれます。


## 読書画面・PWA（更新）

本棚の上部は「新規」「インポート」の順です。テーマ切り替えは読書画面のフッターにあります。フッターは明／ゴの書体トグル、太陽／月のテーマトグル、レイアウトボタンのみ。レイアウトモーダルで判型と文字サイズを調整します。上部のメモ一覧は独立した画面で、項目を押すと読書画面の該当位置へ移動します。

没入モードは画面の余白とページ番号部分を除いた領域に再組版します。モード切り替えでページ数が変わりますが、本文中の位置を保持します。没入中も現在ページ／総ページを表示します。操作表示時はページ・ページバー・フッターを上下に配置し、本文にメニューを重ねません。

HTTPSで公開するとPWAとして利用できます。対応ブラウザのインストール機能、または表示される「アプリを追加」から追加してください。iPhone/iPadではSafariの共有メニューから「ホーム画面に追加」を選択します。初回オンラインアクセスでService Workerの準備が終わった後、オフラインで起動し保存済みの本を読めます。本文は端末のlocalStorageに保存されます。ブラウザとホーム画面アプリで保存領域が分かれる環境では、読書データのエクスポート／インポートで移行してください。HTML書き出し版は単独で動作し、Service Workerを登録しません。


## 本の編集

ライブラリーの各本の「編集」から、タイトル、サムネイル画像、画像を使わない場合の背景色・タイトル色・縦書き／横書きを設定できます。PNG・JPEG・WebPを受け付け、長辺720px以下のJPEGに縮小してブラウザに保存します。画像の解除も可能です。表紙設定はHTMLと読書データのエクスポートに含まれます。

「本を削除」は確認後に本文、しおり、ハイライト、表紙、編集下書きを削除します。削除した本や最初のサンプルを自動復活させません。保存領域不足の場合は編集画面にエラーを表示し、保存を確定しません。
